## 11. Known Issues & Observations

### Issue 1: API Base URL Mismatch (NEEDS ATTENTION)
- **Severity:** MEDIUM
- **Description:**
  - `.env.local` configured to use: `http://localhost:8081/api/v1`
  - But apiClient in `lib/api-client.ts` has fallback: `http://localhost:8081/api/v1`
  - Student service correctly uses endpoints under this base
  - Configuration service uses `/config/settings` endpoints
- **Recommendation:** Verify backend is running on port 8081, not 8080

### Issue 2: Configuration Service Endpoints
- **Severity:** LOW
- **Description:**
  - Frontend uses `/config/settings` endpoints
  - API spec mentions `/api/v1/configurations`
  - Needs alignment with actual backend implementation
- **Recommendation:** Verify backend endpoint paths during integration testing
