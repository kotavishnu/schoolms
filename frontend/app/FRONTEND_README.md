# School Management System - Frontend Application

A modern, responsive React application for managing school operations, built with React 19, TypeScript, Vite, and Tailwind CSS.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Access at http://localhost:5173
```

## Prerequisites
- Node.js 18+
- npm 9+
- Backend services running (ports 8081, 8082)

## Key Features
- Student Management (CRUD operations)
- Configuration Management
- Real-time Dashboard Statistics
- Responsive Design
- Form Validation with Zod
- Toast Notifications

## API Endpoints
- Student Service: http://localhost:8081
- Configuration Service: http://localhost:8082
