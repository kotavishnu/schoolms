## Implementation Details

### 1. Configuration Domain Model

**File:** `domain/model/Configuration.java`

```java
@Getter
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class Configuration {
    private Long id;                    // Auto-generated primary key
    private ConfigCategory category;    // GENERAL, ACADEMIC, FINANCIAL
    private String key;                 // Configuration key (unique per category)
    private String value;               // Configuration value (string representation)
    private String description;         // Human-readable description
    private DataType dataType;          // STRING, NUMBER, BOOLEAN, JSON
    private Boolean isEncrypted;        // Encryption flag
    private Long version;               // Optimistic locking
    private LocalDateTime updatedAt;    // Last update timestamp
}
```

**Design Decisions:**
- Pure Java class with no framework dependencies
- Lombok annotations for boilerplate reduction
- Builder pattern for flexible object creation
- No business logic methods (unlike Student domain model)
- Immutable by default (only getters exposed)

**Fields Mapping:**
| Field | Type | Purpose | Notes |
|-------|------|---------|-------|
| id | Long | Primary key | Auto-generated by database |
| category | ConfigCategory | Group settings | GENERAL, ACADEMIC, FINANCIAL |
| key | String | Unique identifier | Unique within category |
| value | String | Configuration value | Stored as string, parsed by dataType |
| description | String | Documentation | Human-readable explanation |
| dataType | DataType | Value type | STRING, NUMBER, BOOLEAN, JSON |
| isEncrypted | Boolean | Security flag | True if value is encrypted |
| version | Long | Concurrency control | Optimistic locking version |
| updatedAt | LocalDateTime | Audit | Last modification timestamp |

### 3. DataType Enum

**File:** `domain/model/DataType.java`

```java
public enum DataType {
    STRING,   // Text values (e.g., "ABC School", "2025-2026")
    NUMBER,   // Numeric values (e.g., "500", "3.5")
    BOOLEAN,  // True/false values (e.g., "true", "false")
    JSON      // JSON objects/arrays (e.g., {"theme":"light"})
}
```

**Purpose:** Defines the data type of configuration values for validation and parsing

**Why String Storage?**
All values are stored as strings in the database for flexibility. The `dataType` field indicates how the string should be parsed when retrieved.

**Example Usage:**
```java
Configuration maxStudents = Configuration.builder()
    .category(ConfigCategory.GENERAL)
    .key("MAX_STUDENTS")
    .value("500")              // Stored as string
    .dataType(DataType.NUMBER) // Indicates this should be parsed as number
    .build();
```

### 4. BusinessException (Abstract Base Class)

**File:** `domain/exception/BusinessException.java`

```java
public abstract class BusinessException extends RuntimeException {
    public BusinessException(String message) {
        super(message);
    }

    public BusinessException(String message, Throwable cause) {
        super(message, cause);
    }
}
```

**Design Rationale:**
- Abstract class ensures it cannot be instantiated directly
- Extends RuntimeException for unchecked exception behavior
- Provides consistent constructor signatures for all business exceptions
- Allows exception handlers to catch all business exceptions with single catch block

### 5. ConfigurationNotFoundException

**File:** `domain/exception/ConfigurationNotFoundException.java`

```java
public class ConfigurationNotFoundException extends BusinessException {
    public ConfigurationNotFoundException(Long id) {
        super(String.format("Configuration not found with id: %d", id));
    }

    public ConfigurationNotFoundException(ConfigCategory category, String key) {
        super(String.format("Configuration not found with category: %s and key: %s", category, key));
    }
}
```

**Constructor Patterns:**
1. **By ID:** Used when searching by primary key
2. **By Category + Key:** Used when searching by composite natural key

**Usage Example:**
```java
// Throw by ID
throw new ConfigurationNotFoundException(1L);
// Message: "Configuration not found with id: 1"

// Throw by category and key
throw new ConfigurationNotFoundException(ConfigCategory.GENERAL, "SCHOOL_NAME");
// Message: "Configuration not found with category: GENERAL and key: SCHOOL_NAME"
```

### 6. ConfigurationRepository Interface

**File:** `domain/repository/ConfigurationRepository.java`

```java
public interface ConfigurationRepository {
    Configuration save(Configuration configuration);
    Optional<Configuration> findById(Long id);
    Optional<Configuration> findByCategoryAndKey(ConfigCategory category, String key);
    List<Configuration> findByCategory(ConfigCategory category);
    List<Configuration> findAll();
    void delete(Configuration configuration);
    boolean existsByCategoryAndKey(ConfigCategory category, String key);
}
```

**Method Summary:**

| Method | Return Type | Purpose | Usage |
|--------|-------------|---------|-------|
| save | Configuration | Persist configuration | Create or update |
| findById | Optional<Configuration> | Find by primary key | Get by ID |
| findByCategoryAndKey | Optional<Configuration> | Find by composite key | Get specific setting |
| findByCategory | List<Configuration> | Filter by category | Get all GENERAL settings |
| findAll | List<Configuration> | Get all configurations | Admin view |
| delete | void | Remove configuration | Delete setting |
| existsByCategoryAndKey | boolean | Check existence | Prevent duplicates |

**Design Principles:**
- Interface defined in domain layer (DDD pattern)
- Implementation will be in infrastructure layer
- Returns domain models, not JPA entities
- Uses Optional for nullable returns
- No Spring Data annotations (pure interface)

**Query Patterns:**
```java
// Find by primary key
Optional<Configuration> config = repository.findById(1L);

// Find by composite natural key
Optional<Configuration> config = repository.findByCategoryAndKey(
    ConfigCategory.GENERAL,
    "SCHOOL_NAME"
);

// Get all configurations in a category
List<Configuration> generalConfigs = repository.findByCategory(ConfigCategory.GENERAL);

// Check if configuration exists
boolean exists = repository.existsByCategoryAndKey(ConfigCategory.GENERAL, "SCHOOL_NAME");
```
